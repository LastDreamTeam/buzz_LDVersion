# LD 中文用词与边界

目标是让中文用户理解功能，不逐字翻译英文。此表约束 LD 新增和引用词库的适配；不能据此修改协议、命令、品牌、模型 ID、用户姓名或聊天正文。

| 英文概念 | LD 用词 | 原因 / 例外 |
| --- | --- | --- |
| Agent | 智能体 | 不称机器人雇员；网络 proxy 仍是代理 |
| Channel / Community | 频道 / 社区 | 沿用聊天产品含义，不等同项目或组织 |
| Thread | 话题 / 话题回复 | 同一消息下的回复，不译成程序线程；CPU、worker 等技术语境仍是线程 |
| Direct message | 私聊 | 与频道消息区分；不是电子邮件 |
| Huddle | 语音会议 | 即时语音交流，可包含共享屏幕和智能体；避免不明所以的“小聚” |
| Canvas（频道） | 共享文档 | 原功能是 Markdown 协作文档，不是绘图软件；Drawing canvas 是图片标注画布 |
| Harness | 运行器 | 执行智能体的工具，如 Claude Code、Codex；不等于模型服务商 |
| Runtime | 运行环境 | 描述智能体实际执行环境/配置；命令和程序名称原样显示 |
| Provider | 服务商 | AI / 算力服务提供方；不意味着每项都收费 |
| Repository / Commit | 代码仓库 / 提交 | 避免“存储库”“承诺”等脱离开发语境的直译 |
| Pull request / PR | 拉取请求 / PR | 保留 GitHub 常见术语，实际用途是代码审阅与合并申请，不改成下载请求 |
| Issue | 任务 / 议题 / 问题，按位置审查 | 项目工作项不一定是缺陷；无法确认时不全局替换成 Bug 或任务卡 |
| Archive / Unarchive | 归档 / 取消归档（恢复） | 归档不是删除，恢复不是恢复备份；确认提示必须保留后果说明 |
| Open | 打开 / 公开 / 待处理，按位置审查 | 频道可见性用“公开”，按钮用“打开”；状态枚举不翻译 |
| Reaction | 表情回应 | 不和正文回复混淆 |
| Identity / Secret key | 身份 / 私钥 | 不假装存在普通账号密码登录；安全提示不得弱化 |

## 词库优先级

1. 明确审查的文件级展示词条（`reviewed-literals.json`）。例如创建频道模板摘要里的 Open → 公开。
2. LD 人工词库（`zh-CN.json`）。包括按钮长度、隐私提示、中文自然表达与本表术语。
3. 固定来源目录中的精确英文展示匹配（`reference-catalog.mjs`）。同英文不同译法的条目排除；有 LD 人工决策时才覆盖。
4. 不认识或无法安全处理的内容保留原英文。不能用自动翻译猜测用户数据。

来源目录保持原始键值；LD 改词规则在独立适配器中，不直接改第三方目录。原作者、许可证与固定版本见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 当前限制

- 这里只处理界面固定文案；模型回复语言由智能体自身决定。
- AST 覆盖不是完整语义国际化框架。英文拼接句、运行时返回的错误、原生系统菜单和未审查展示常量可能仍是英文。不能把覆盖数字当成全界面完成率。
- 模板参数只允许数量、顺序和求值次数不变。需要中文语序重排或复数逻辑重构的条目暂不自动接入。
- 后续官方合并国际化框架时，应迁移词库和偏好到官方接口、移除重复外层接入，不能同时运行两套语言系统。
